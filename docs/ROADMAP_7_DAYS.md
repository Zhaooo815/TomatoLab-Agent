# Seven-day student roadmap

| Day | Task |
|---|---|
| 1 | 跑通本地页面，把七环节与四道闸门对着协议原文核对一遍，记录差异。 |
| 2 | 在 `data/tomato.ts` 补问答条目，明确 `source` 与 `tag`，并写测试。 |
| 3 | 复核加药表与母液浓度的折算口径，验证 `dosing.ts` 的正反向换算。 |
| 4 | 给台账加一条可测试的规则（阶段相邻推进、回退填原因），补测试。 |
| 5 | 检查问答的「未覆盖」分支——协议没有的问题必须落空，不能硬答。 |
| 6 | 完成桌面与手机宽度下的界面检查，修布局与文案问题。 |
| 7 | 运行 `npm --prefix frontend run build` 与 `npm --prefix frontend test`，写实验报告并复核数据边界。 |
